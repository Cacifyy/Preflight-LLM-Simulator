How it works

Most architecture decisions happen in a conversation or a drawing. PreFlight adds numbers to that conversation — so you know whether your design will hold before you build it.

01 — Compose

Drag your pipeline

Pick from retrieval nodes, 25+ real LLM models, deployment platforms, and custom components. Place them on the canvas.

02 — Connect

Wire the graph

Drag from output ports to input ports to define the flow. Each connection is reflected immediately in the simulation.

03 — Analyse

Read the forecast

p50–p99 latency, throughput ceiling, cost per request, and a bottleneck analysis with specific fix suggestions.

04 — Iterate

Change anything

Swap models, add caches, change platforms. Every edit recalculates instantly. Export the result as PNG or JSON.

Features

PreFlight is a single-file tool — no account, no installation, no backend. Open it, design your pipeline, and share the file.

Latency model

p50 through p99, per node

Uses log-normal distribution modeling between your p50 and p95 inputs to estimate any percentile. Toggle which percentiles appear in the stats panel. Click any node to see its individual contribution to total latency.

Model library

25+ real models with actual pricing

GPT-4o, Gemini 2.5, Claude, Llama, Mistral, DeepSeek and more — each pre-loaded with published latency, context window size, and cost per million tokens. Search by name or provider.

Deployment

Cold-start penalties modeled

Vercel, AWS Lambda, Cloudflare Workers, Railway, Fly.io, and Cloud Run — each with realistic warm and cold-start latency. The p95 gap between warm and cold is often the most surprising number in a pipeline design.

Bottleneck analysis

Specific fixes, not generic warnings

When a node is the throughput ceiling, PreFlight explains why, quantifies the impact, and gives three concrete steps to resolve it — tailored to that specific node type.

Editable nodes

Override any default with your real numbers

Sidebar defaults can be changed globally for a node type. Individual canvas nodes can be overridden per-instance. Custom nodes let you model any component with your own p50, p95, tps, and cost.

Export

PNG screenshot · JSON save/load

Export your pipeline as a PNG to drop into a design doc or share on Slack. Export as JSON to save your work or share with a colleague. Import JSON to pick up where you left off.
